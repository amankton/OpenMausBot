# Local meeting capture worker

This is a native Windows, audio-only subscriber for Chief Shared Workspace.
It never publishes media, opens a physical device, joins automatically, or sends
meeting text to a remote model. Love issues a room token only after individual
consent from the exact current participant sessions. Attendance changes,
withdrawal, authorization loss, reconnect or lease loss stop listening.

The worker uses Python 3.11 in `.chief-local/capture-venv`, separate from other
apps. `requirements.txt` pins direct dependencies; `requirements-lock.txt`
records the complete reviewed environment. `dependency-provenance.json` records
the installed wheel URLs and hashes. The English CPU model is
`Systran/faster-whisper-tiny.en`, revision
`0d3d19a32d3338f10357c0889762bd8d64bbdeba` (MIT). Each of its four runtime files
is verified against the pinned repository's Git blob IDs or LFS SHA256 before
installation and again against fixed SHA256 values at worker startup.

The model was copied from an existing cache, without starting VoiceStudio or
copying its recordings. The worker loads only local files. Model licensing is
documented at https://huggingface.co/Systran/faster-whisper-tiny.en and the
upstream Whisper license is retained alongside this document.

Use a private configuration generated by the deployment preparation script:

```powershell
.\.chief-local\capture-venv\Scripts\python.exe integrations/meeting-capture/worker.py --config .chief-local/meeting-capture/worker.json
```

The config contains only local endpoints, model/audio directories and a separate
worker credential. Never put this credential in command arguments, source files,
browser storage or public receipts. The process holds an exclusive OS file lock.

Limits are eight people, one capture/transcription job at a time, sixty minutes,
and 256 MiB of mono 16 kHz PCM. Independent speaker tracks retain attribution
without voice identification. Raw audio lives in private UUID directories,
is trimmed to the server's authoritative stop time before transcription, and
is deleted only after server acknowledgment. Failed audio can be explicitly
retried without rejoining a room and expires after 72 hours. Transcripts and
suggested decisions/action items require human review; personal-agent handoff
is a separate reviewed import that creates an unsent draft.

Verification:

```powershell
.\.chief-local\capture-venv\Scripts\python.exe -m unittest discover -s integrations/meeting-capture -p 'test_worker*.py' -v
```

`verify_local_asr.py` accepts only a short generated mono fixture. Its real CPU
ASR receipt is in `docs/verification/evidence/chief-local-asr.json`. This isolated
test alone does not prove the complete meeting capture integration.

The lifecycle regression suite also covers a delayed capture-stop response
arriving after the server has acknowledged the stop. It must stop listening
without cancelling authorized transcription; a fresh processing authorization
failure still cancels ASR. Diagnostic logs contain only error classes, status
codes and source line locations, never exception messages or captured content.
