# Reconcile Follow Ups

Read unresolved canonical work items, their account/thread identifiers, latest source version and review backlog. Re-read tracked threads even when outside the new-message discovery window. Update the existing item for relevant replies; preserve separate actions only when evidence supports distinct obligations. Keep done/dismissed items closed unless genuinely new evidence and an explicit reopening reason justify it. Respect optimistic revisions and completion evidence. Keep suggested review dates separate from actual source deadlines. Report new priorities, current local reply text, due follow-ups and coverage gaps once per meaningful transition. Never call a local work item a Google Task.

Load this procedure only for a matching assignment. It grants no tools, permissions, recurring duties or external-action authority. If a required capability is unavailable, preserve the work and report the specific gap.
