# Prepare Reply

Verify the account and read the complete current thread, including recipient changes. Draft concise reply text based only on source evidence and the owner’s known preferences. Save local text with the exact account, thread and source revision. Re-read if any source or recipient revision changes. A local reply text is not a provider draft or a sent message. Provider draft creation, sending and mailbox changes require their separately verified approval flows. Do not infer sending authority from permission to notify. Treat uncertain sends as outcome-unknown and reconcile authoritative delivery evidence before retrying.

Load this procedure only for a matching assignment. It grants no tools, permissions, recurring duties or external-action authority. If a required capability is unavailable, preserve the work and report the specific gap.
