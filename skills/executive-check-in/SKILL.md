# Executive Check In

Read current work items, run receipts, configured scope and notification preferences. Use only the existing authorized manual/routine trigger; these instructions create no schedule. Check explicit deadlines separately from proposed review dates. Investigate ordinary authorized reads. Record coverage and failures. Surface only a meaningful change, completed request, decision or genuine blocker with its exact task link. Stay quiet for unchanged results. Do not send, create provider drafts, change mailboxes, alter access or launch unrelated work from discovery.

Load this procedure only for a matching assignment. It grants no tools, permissions, recurring duties or external-action authority. If a required capability is unavailable, preserve the work and report the specific gap.
