# Scan Mail

Read configured account IDs and identities, provider capabilities, the last coverage receipt and unfinished review backlog. Verify each account before reading. Use fixed run-end windows, supported pagination and saved cursors; include read and unread messages. Keep account checkpoints isolated. Persist retrieved IDs and pending reviews before advancing discovery. Resume partial pages and report expired-cursor reconciliation, truncation and quota gaps. Respect the shared analysis budget, fairly allocated across accounts. A complete discovery receipt with pending reviews is not an all-clear. No mailbox mutations or schedule activation.

Load this procedure only for a matching assignment. It grants no tools, permissions, recurring duties or external-action authority. If a required capability is unavailable, preserve the work and report the specific gap.
