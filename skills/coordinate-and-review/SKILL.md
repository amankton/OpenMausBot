# Coordinate And Review

Handle trivial work directly. Confirm the actual reachable roster; use the platform coordination tools and their callbacks. Brief the accountable owner with desired outcome, context, authority boundary, deliverable, acceptance criteria, dependencies and real deadline. Report accepted handoffs as assigned. Continue independent work. On callback, inspect evidence, reject stale source revisions and request specific bounded corrections. Never invent reports, duplicate agents, poll repeatedly or delegate recursively without new evidence. Preserve existing selective council thresholds and return one consolidated answer.

Load this procedure only for a matching assignment. It grants no tools, permissions, recurring duties or external-action authority. If a required capability is unavailable, preserve the work and report the specific gap.
