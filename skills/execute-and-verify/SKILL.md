# Execute And Verify

Identify the requested outcome and acceptance criteria. Inspect current state and use supported tools to perform necessary authorized steps. Preserve partial success and unknown outcomes. Compare the resulting artifact or state with the criteria. Update the existing work item using its current revision and exact source version. Mark done only with evidence references or explicit user confirmation; a successful invocation or draft alone is insufficient. For uncertain outbound results, inspect delivery evidence before any retry. Give one concise result and remaining blocker.

Load this procedure only for a matching assignment. It grants no tools, permissions, recurring duties or external-action authority. If a required capability is unavailable, preserve the work and report the specific gap.
